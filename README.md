# 🌸 Blush Café — Café Website

A modern, responsive full-stack café website .Featuring table reservations, contact enquiries, animations, and an interactive map.

## 🏷️ Industry

Restaurant / Café

## 🎯 Objective

To build a user-friendly café website with a reservation system and a backend-powered contact form using **MongoDB and SMTP email integration**.

## 🛠️ Technologies Used

**Frontend:** HTML5, CSS3, JavaScript, GSAP, ScrollTrigger, Leaflet.js, SVG

**Backend:** Node.js, Express.js, MongoDB, Mongoose, Nodemailer, CORS, dotenv

## ✨ Features

* Responsive café website with mobile navigation
* Smooth scrolling and scroll animations
* 3D card tilt effects
* Table reservation system with MongoDB
* Contact form with backend validation and SMTP email
* Admin dashboard for managing enquiries
* Reviews slider and image gallery with lightbox
* Interactive Leaflet map

## 🚀 How to Run Locally

### Frontend

Open `frontend/index.html` using **VS Code Live Server**.

### Backend

```bash
cd backend
npm install
npm run dev
```

The backend runs on:

```text
http://localhost:5000
```

Create a `.env` file in the `backend` folder using `.env.example` and add your MongoDB and SMTP credentials.
